研究所推甄｜專題研究成果

研究題目
基於低維狀態輸入之 DQN 與 Double DQN 在 Flappy Bird 環境中的樣本效率與訓練穩定性比較

────────────────────────────────────────
第 1 頁｜研究動機與實驗設計
────────────────────────────────────────

01｜研究背景與動機

深度強化學習可讓代理人在與環境互動的過程中，透過獎勵訊號逐步學習決策策略。DQN（Deep Q-Network）利用神經網路近似動作價值函數，但在計算下一狀態價值時，動作選擇與價值估計皆來自最大化操作，因此可能累積 Q 值高估誤差。Double DQN 則將下一步動作的選擇與價值評估分開，理論上能降低價值高估問題。

本研究以 Flappy Bird 作為強化學習實驗環境，比較 DQN 與 Double DQN 在相同訓練條件下的學習表現。為降低影像辨識與卷積運算對實驗的干擾，研究不直接使用遊戲畫面，而是將環境轉換為四維數值狀態，使計算資源集中於演算法本身的差異。實驗採用固定互動步數、多個隨機種子及獨立策略評估，以避免僅根據單次訓練結果做出結論。

02｜研究目的

1. 樣本效率：比較 DQN 與 Double DQN 在相同環境互動步數下的學習速度與訓練曲線面積。

2. 訓練穩定性：分析不同訓練種子之間的結果變異，以及訓練後期 episode 分數的波動程度。

3. 最終策略表現：使用不含隨機探索的 Greedy Evaluation 評估完成訓練後的策略，區分訓練期間分數與實際策略能力。

03｜研究方法與實驗設計

一、環境與輸入狀態

每個 timestep 的輸入由下列四個經正規化的數值組成：

（1）小鳥目前的垂直高度。
（2）小鳥目前的垂直速度。
（3）小鳥與下一根水管之間的水平距離。
（4）小鳥相對於下一個水管缺口中心的垂直高度差。

動作空間包含兩種選擇：不拍翅與拍翅。獎勵函數設定為每存活一步獲得 +0.1、通過一根水管獲得 +1、碰撞死亡獲得 −1。

二、模型架構

DQN 與 Double DQN 使用相同的多層感知器，網路結構為 4→256→256→2。兩層隱藏層皆使用 ReLU 啟動函數，輸出層分別估計兩個動作的 Q 值。

兩種方法皆使用 online network 與 target network。DQN 直接從 target network 的下一狀態輸出中選取最大 Q 值；Double DQN 先由 online network 選擇下一個動作，再由 target network 評估該動作的價值。除了目標值計算方法以外，其餘條件保持一致。

主要超參數如下：

・最佳化器：Adam
・損失函數：Huber loss
・Learning rate：0.0001
・折扣因子 γ：0.99
・Gradient clipping norm：1.0
・Target network soft update 係數 τ：0.005
・Replay memory 容量：50,000
・Minibatch size：128
・Replay warm-up：10,000 timesteps
・模型更新頻率：每 4 個環境 timesteps 更新一次

三、探索策略與訓練預算

訓練前 10,000 timesteps 為 replay warm-up，epsilon 維持在 0.1。暖機完成後，epsilon 依 global timestep 線性下降，於接下來 200,000 timesteps 由 0.1 降至 0.01。

每次訓練的固定預算為 500,000 environment timesteps。DQN 與 Double DQN 分別使用 seeds 42、43、44、45、46，共完成 10 次獨立訓練及 5 組配對比較，總計 5,000,000 個訓練環境步數。

四、公平比較原則

兩種演算法使用相同的四維狀態、動作空間、獎勵函數、神經網路架構、訓練步數、探索率排程、replay memory、最佳化參數與配對隨機種子。如此可降低其他變因造成的影響，使觀察到的差異較能反映演算法設計與隨機訓練變異。

五、評估方法

訓練曲線使用最近 50,000 timesteps 內完成的 episodes 計算移動平均，並以每 10,000 timesteps 為跨 seed 對齊點。

樣本效率以固定步數學習曲線的面積（AUC）表示；訓練後期表現則使用最後 20% 訓練區段的平均分數與 episode 分數標準差。峰值至後期衰退率用於觀察模型在到達最高訓練表現後是否發生退化。

最終 Greedy Evaluation 將 epsilon 設為 0，使模型完全依據 Q 值選擇動作。每個完成訓練的模型使用 evaluation seed 999 執行 50 episodes，因此每種演算法共有 250 個 evaluation episodes。

04｜實驗結果與分析

五組訓練種子的彙整結果如下，數值表示跨 seed 平均值 ± 1 個樣本標準差。

指標                              DQN                  Double DQN
──────────────────────────────────────────────────────────────
訓練曲線 AUC                     3.04 ± 0.95          3.35 ± 0.77
最後 20% 平均分數                5.31 ± 1.21          5.14 ± 0.78
後期 episode 分數標準差          5.35 ± 1.25          5.19 ± 1.01
最終 greedy 平均分數             18.22 ± 15.92        6.64 ± 2.64
峰值至後期衰退率                 18.18% ± 6.10%       22.56% ± 8.91%

一、樣本效率

Double DQN 的訓練曲線 AUC 為 3.35，高於 DQN 的 3.04，代表在固定 500,000-step 預算下，Double DQN 整體訓練分數略高。Double DQN 的跨 seed 標準差也較小，顯示五次訓練的樣本效率較為一致。然而，兩者差距不大，目前結果較適合描述為 Double DQN 略有優勢，不能直接宣稱存在顯著差異。

二、訓練後期表現與穩定性

DQN 與 Double DQN 在最後 20% 訓練區段的平均分數分別為 5.31 與 5.14，整體表現接近。Double DQN 的跨 seed 標準差與後期 episode 分數標準差略低，代表其結果稍微集中，但優勢幅度有限。

Double DQN 的峰值至後期衰退率為 22.56%，高於 DQN 的 18.18%。因此，本次實驗沒有觀察到 Double DQN 在所有穩定性指標上都優於 DQN。這也顯示穩定性必須透過多個指標共同判讀，不能只根據單一曲線或理論預期下結論。

三、最終 Greedy Evaluation

DQN 的最終 greedy evaluation 平均分數為 18.22，高於 Double DQN 的 6.64，但 DQN 的跨 seed 標準差達 15.92，明顯高於 Double DQN 的 2.64。

進一步檢查個別訓練結果後發現，DQN seed 43 的 greedy 平均分數為 45.96，明顯高於其他 DQN seeds，因而大幅拉高整體平均值。這表示 DQN 在本次實驗中出現一個表現非常好的模型，但不同種子之間的再現性較低。Double DQN 的平均分數較低，結果則相對集中。

因此，目前證據不能支持「DQN 普遍優於 Double DQN」或「Double DQN 必然優於 DQN」。較合理的解釋是：Double DQN 在訓練曲線與跨 seed 一致性方面略有優勢；DQN 則可能產生表現較高的最終策略，但結果高度依賴隨機種子。

05｜研究結論與反思

本研究完成低維狀態 Flappy Bird 環境中的 DQN 與 Double DQN 公平比較。結果顯示，即使使用相同模型架構與超參數，不同隨機種子仍可能造成明顯差異。若只呈現單次訓練或最高分數，容易對演算法能力做出過度推論；加入配對 seeds、固定 timestep 預算、標準差及獨立 greedy evaluation，才能較完整地呈現模型的學習效率與可靠程度。

此外，訓練期間的 epsilon-greedy 分數與最終 greedy 策略表現並不完全一致。訓練曲線包含隨機探索行為，而 greedy evaluation 反映固定策略的實際表現，因此兩者應分開解讀。預測 Q 值持續上升也只能作為可能發生高估的線索；在缺少真實 action value 的情況下，不能單憑 Q 值曲線證明高估。

研究限制與後續工作

目前的 greedy evaluation 只在 500,000 timesteps 訓練完成後執行，因此能比較最終策略表現，但無法直接證明策略在不同訓練階段逐漸收斂或維持穩定。後續實驗將於 50,000、100,000、150,000，直到 500,000 timesteps 保存 checkpoints，並使用相同的 evaluation seeds、epsilon＝0 進行階段性評估，以建立真正的 evaluation learning curve。未來亦可增加訓練 seeds、計算信賴區間，並比較不同網路規模與探索策略。

個人實作與研究能力

本專題完成四維狀態環境、DQN、Double DQN、target network、經驗回放、配對 seed 自動化訓練、實驗設定驗證、CSV 紀錄及 Python 圖表分析。研究過程中，我從異常學習曲線回溯 epsilon 衰減與評估流程，並重新設計固定 timestep、多 seed 與 greedy evaluation 實驗，使結論建立在可重現的數據上，而不是單一模型的最高分數。
